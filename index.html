Meeting Room Occupancy Detection

A monitoring dashboard that compares Google Calendar bookings with camera-based person detection, so employees can trust the room calendar again.

  • .NET 8
  • ASP.NET Core
  • SQLite (EF Core)
  • Google Calendar API
  • ONNX Runtime
  • React
